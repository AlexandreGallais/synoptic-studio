# Feedback on the agent's work

Every critique the Product Owner makes of how the agent worked, written as soon as it is said: what happened, what the agent should have done, and what now prevents it — in neutral words, never quoted. Requests and ideas go to the [improvement log](./improvements.md).

At each retrospective, the rows are grouped into the habits sheet of [Working with the agent](../playbook/agent.md#lessons-from-the-product-owner), then the log is emptied. E01's rows: [E01 retrospective](./retrospectives/E01-retrospective.md); E14's: [E14 retrospective](./retrospectives/E14-retrospective.md); E15's: [E15 retrospective](./retrospectives/E15-retrospective.md).
