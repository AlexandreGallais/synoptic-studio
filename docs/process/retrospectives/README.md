# Retrospectives

One record per epic retrospective (`RET` story, ADR-0023), named `E01-retrospective.md`. Template: `_retrospective.md` in this folder (not published).

A retrospective reads `npm run metrics -- --since <epic's first day>` ([metrics](../../tooling/metrics.md#at-each-retrospective)): the commands by count and by time, the stories and tasks, the failed calls, the tokens, and its **Tools** section — each Rust tool's calls, failures, median and slowest durations, from the uses each tool records (EN-102) — read as a tools team reviews its tools: unused, failing or slow.
