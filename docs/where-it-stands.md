# Where it stands

The library already draws the shapes of a symbol from numbers — rectangles, polygons, free shapes, round shapes and curves —, places text with real font metrics, and lets the playground select, move, zoom and undo on one drawing. The [playground](https://alexandregallais.github.io/synoptic-studio/playground/) shows it at work.

## Done

| Epic | What it brought |
| --- | --- |
| Draw symbol shapes from numbers | rectangles and polygons with a radius per corner, free shapes whose points are edited, any shape turned by any angle |
| Draw curves | points with handles, round shapes and ellipses |
| Place text in symbols | text measured from the font itself, text in a box, colours, fonts embedded at export |
| Fast tooling | every check and project tool rewritten to answer in seconds |
| Select and move shapes | several shapes on one drawing, selection, moves on whole numbers, undo and redo, zoom and pan |
| The agent's method and tools | the agent's knowledge in its own database, and these short pages |
