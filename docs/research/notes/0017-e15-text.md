# 0017 — Sources of E15: text measured from font metrics and drawn as positioned lines

Spike SP-015, 2026-10-14, for F05 and the later features of E15 (F14 a box of text, F15 fonts and the HTML layer, F16 colors). Two research agents read the sources during the refinement; every page below was read again in the local library before it was cited. The Product Owner chose from this research in round 2 of F05: the library measures and breaks the lines, an HTML layer comes later for browsers (ADR-0052).

## Text in SVG readers

Native `<text>` with one positioned `<tspan>` per line is the only form every reader draws. HTML in a `<foreignObject>` is a browser feature.

| Finding                                                                                                                                                                                                                                                     | Source                                                                                |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `foreignObject` includes elements of another XML namespace, in a browser most likely HTML                                                                                                                                                                   | `REF-MDN-FOREIGNOBJECT`                                                               |
| draw.io's labels in a `foreignObject` "isn't actual SVG, so SVG editors cannot display it"; its "Convert labels to SVG" writes native `<text>` for "SVG editors and platforms that don't support foreign objects"                                           | `REF-DRAWIO-SVG-TEXT`                                                                 |
| Batik: a feature not supported gets "no useful processing"; `foreignObject` attributes and `dominant-baseline` are marked "no"                                                                                                                              | `REF-BATIK-STATUS`                                                                    |
| GE Proficy Operations Hub's SVG editor converts each `tspan` into a `text` element                                                                                                                                                                          | `REF-GE-PROFICY-SVG`                                                                  |

## Font files and their metrics

A TrueType or OpenType file is a directory of tables (`REF-OT-OTFF`: `sfntVersion` 0x00010000 for TrueType outlines, `OTTO` for CFF). Measuring needs only these tables:

| Table  | Gives                                                                                                                                               | Source        |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| `head` | `unitsPerEm`, from 16 to 16384                                                                                                                      | `REF-OT-HEAD` |
| `hhea` | `ascender`, `descender`, `lineGap`, `numberOfHMetrics`                                                                                              | `REF-OT-HHEA` |
| `hmtx` | the advance of each glyph, "always obtained from the 'hmtx' table"; with fewer records than glyphs, the last record's advance applies to the rest   | `REF-OT-HMTX` |
| `cmap` | character to glyph; formats 4 and 12 "are appropriate for most new fonts"; a character with no glyph maps to glyph 0, `.notdef`                     | `REF-OT-CMAP` |
| `kern` | kerning pairs, format 0; "Fonts containing CFF outlines are not supported by the 'kern' table and require use of the GPOS table"                    | `REF-OT-KERN` |
| `GPOS` | lookup type 2, pair adjustment: kerning by glyph pairs (format 1) or by classes (format 2)                                                          | `REF-OT-GPOS` |
| `OS/2` | `fsType`, the embedding permission (0 installable, 2 restricted, 4 preview and print, 8 editable); `yStrikeoutPosition`, `yStrikeoutSize`; `sTypo*` | `REF-OT-OS2`  |
| `post` | `underlinePosition` (top of the underline), `underlineThickness`                                                                                    | `REF-OT-POST` |

Width and line height follow from these numbers (`DERIV-text-width`). Hand-checked on Arial 5.01 (macOS `Arial.ttf`, 2048 units per em, 909 kerning pairs, `fsType` 8): "Hello World" is 10 584 units, 82.6875 at size 16; 82.39844 kerned (one pair, W o, −37); "AVATAR" 64.01563, 59.26563 kerned; line height 18.39844 at 16.

Vertical metrics: `hhea` holds ascender, descender and line gap, but the OpenType specification recommends `OS/2` `sTypoAscender`, `sTypoDescender` and `sTypoLineGap` for new layouts, chosen against `usWin*` by the `USE_TYPO_METRICS` flag (`REF-OT-HHEA`, `REF-OT-OS2`). Arial's three sets differ: `hhea` 1854, −434, 67; `usWin*` 1854, 434; `sTypo*` 1491, −431, 307, flag unset. F05 uses `hhea` (`DERIV-text-width`); which set a browser uses is not sourced (open).

## Embedding fonts (F15)

`@font-face` takes `src: url(…) format(…)`, with `opentype`, `truetype`, `woff` and `woff2` among the formats (`REF-CSS-FONTS-4`); a data URL is the only way a font reaches an SVG used as an image (`REF-MDN-SVG-AS-IMAGE`). An application "must not embed fonts which are not licensed to permit embedding" (`REF-OT-OS2`, `fsType`). F15's spike and ADR-0053 decide the rest.

## The default font

Inter, version 4.1 of 2024-11-16, under the SIL Open Font License 1.1 (`REF-INTER-LICENSE`, `REF-INTER-RELEASE`). The licence allows the font to be "bundled, embedded, redistributed and/or sold with any software", provided each copy carries the copyright notice and the licence; a derivative made "by changing formats" is a Modified Version, which stays under the licence; the licence does not apply "to any document created using the Font Software". Inter's copyright line names no reserved font name. Recorded in `docs/tooling/dependencies.md` (Assets).

## Open

- Which vertical metrics a browser uses (`hhea`, `usWin*` or `sTypo*`) and how it splits the line gap: F15 compares the HTML layer with the positioned lines.
- Inter's kerning: whether its files carry a `kern` table or only `GPOS` pairs, and its `fsType`; EN-031 reads them.
- A right-to-left line in a reader without `direction` (resvg, Batik): its start may be placed on the wrong side; US-031 checks it in the browsers.
