# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**, through GitHub: _Security → Report a vulnerability_ on this repository. Do not open a public issue.

## Scope

- The published library has no runtime dependency.
- Development dependencies are audited on every check and in CI (`npm audit`, Dependabot, dependency review, CodeQL, secret scanning); see `docs/tooling/versions-and-security.md`.
